ALCANCE:

Esta sección se divide en funciones específicas de cada tipo de usuario:
Para “Administrador”:
• Visualización de canchas disponibles filtradas por fecha y hora.
• Realización y cancelación de reservas.
• Asignación de implementos deportivos en función de la reserva realizada.

Para “SuperAdministrador”:
• Eliminación de cuentas de usuarios con rol “Administrador”.
• Acceso a un panel exclusivo para la gestión de recursos económicos.


Panel de Administración Avanzada:
Este panel será accesible únicamente para el Superadministrador, y permitirá una gestión completa y detallada del sistema:
• Añadir, editar o eliminar información relacionada con las canchas deportivas (horarios de uso, tarifas).
• Generación de reportes de reservas por fecha, cancha, ingresos obtenidos.
